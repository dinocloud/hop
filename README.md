# HOP · WhatsApp

Bot de WhatsApp para los Puntos HOP sobre AWS End User Messaging Social y Amazon Bedrock AgentCore.

- Aviso proactivo cuando el paquete llega al Punto HOP.
- Consulta "¿dónde está mi paquete?" respondida por un agente.

La documentación de arquitectura, deploy y verificación se agrega con cada PR.
